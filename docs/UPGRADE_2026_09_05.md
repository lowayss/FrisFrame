# 2026-09-05 로컬 통합 업그레이드

GitHub main 2b881bc와 stage-blocking-lab의 기존 미커밋 수정사항을
codex/frisframe-upgrade-20260905에서 통합했다. 원래 작업 폴더는 보존했다.

## 포함한 기능

- Physical Camera: 보안 연결, 폰 방향 추적, 지원 기기에서 WebXR 카메라 기준 6DoF 이동.
- RAW / HANDHELD / CINEMA 안정화, RECENTER.
- 촬영 Take 저장·선택, 비파괴 미리보기, 명시적 타임라인 적용.
- MCP 촬영 경로 및 순서별 움직임 문맥 전달.
- 기존 배우 색상, 동선, 자세, 트래킹, 고스트 제거 수정 유지.

## 이번 추가 수정

- 폰 페이지에 누락된 프리뷰 갱신 상수를 전달해 런타임 ReferenceError 해결.
- 프리뷰/입력 요청 타임아웃과 입력 단일 요청 처리.
- 모션 중지 이후 센서 이벤트 재활성화 방지, null 센서 값 거부.
- 비보안 페이지에서는 Physical Camera 연결 안내 유지.
- 높이 위/아래 버튼 연결; 포인터 캡처 해제·화면 전환 시 조이스틱 해제.
- 폰/패드 모드에서도 프리뷰 이동·크기 조절·멀티캠 버튼 사용 가능.
- 보조 스크립트 순차 주입과 신규 Physical Camera 모듈 동시 유지.
