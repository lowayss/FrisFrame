# FrisFrame 사용자 가이드

FrisFrame은 **Seedance Video Reference에 넣을 프리비즈 MP4를 만드는 키프레임 기반 프리비즈 도구**입니다.

FrisFrame 안에서 최종 AI 영상을 생성하거나 레퍼런스 이미지를 해석하지 않습니다. 역할은 카메라, 배우, 소품, 타이밍과 공간 관계를 **재현 가능한 키프레임 상태**로 만들고 프리비즈 영상으로 출력하는 것입니다.

```text
수동 편집 또는 MCP 보조 편집
        ↓
2D / 3D 블로킹
        ↓
카메라 · 배우 · 소품 키프레임
        ↓
프리비즈 확인
        ↓
기준 프레임 / 첫·끝 프레임 / 프리비즈 MP4
        ↓
Seedance Video Reference
```

## 1. 실행

브라우저 버전은 로컬 서버로 실행합니다.

```bash
python3 server.py --port 8766
```

브라우저에서 다음 주소를 엽니다.

```text
http://127.0.0.1:8766/
```

전체 회귀 검사는 다음 명령으로 실행합니다.

```bash
python3 quality_check.py
```

데스크톱 설치본은 로컬 서버, FFmpeg와 MCP stdio 실행파일을 함께 포함하므로 일반 사용자는 Python이나 FFmpeg를 별도로 설치할 필요가 없습니다.

## 2. 기본 작업 흐름

1. 프로젝트와 컷을 준비합니다.
2. `블로킹` 화면에서 무대, 배우, 소품과 카메라를 배치합니다.
3. 렌즈, 카메라 높이, pan/tilt와 필요한 tracking을 설정합니다.
4. 원하는 시간으로 이동해 `키 +`를 눌러 현재 상태를 키프레임으로 기록합니다.
5. 같은 방식으로 카메라와 배우/소품의 다음 상태를 만듭니다.
6. 2D 또는 3D에서 재생하며 카메라 이동, 화면 방향과 타이밍을 확인합니다.
7. 필요하면 기준 프레임 또는 첫·끝 프레임을 출력합니다.
8. 최종적으로 `프리비즈 MP4`를 출력해 Seedance의 Video Reference로 사용합니다.

FrisFrame은 배우의 자연스러운 보조 동작을 임의로 만들지 않습니다. 자동 걷기 사이클, 팔 흔들기, 호흡, 몸 바운스 같은 동작은 기본적으로 생략하고 **Root 위치·방향·높이·작성한 Pose**만 전달합니다.

## 3. 작업 화면

### 좌우 패널

좌우 패널은 접을 수 있습니다. 작업 공간을 넓게 보고 싶을 때는 `Shift+F`로 포커스 모드를 전환할 수 있습니다.

기본 작업에서 자주 쓰는 패널은 우선 보이고, 세부 카메라 설정·공간 프리셋·세부 속성·포즈 편집 등은 접을 수 있는 보조 영역에 들어갑니다. 패널과 세부 영역의 열림 상태는 데스크톱에서 기억됩니다.

### 렌즈 프리셋

렌즈 입력 바로 아래의 다음 프리셋을 빠르게 사용할 수 있습니다.

- 14mm
- 24mm
- 35mm
- 50mm
- 85mm
- 135mm

### 주석 도구

세로 주석/그리기 도구는 기본적으로 숨겨져 있습니다. 필요한 경우 작은 연필 버튼 또는 `Shift+A`로 열고 닫습니다.

## 4. 2D / 3D 전환

상단의 2D/3D 전환 버튼을 사용하거나 `V`를 눌러 마지막 작업 뷰 사이를 빠르게 전환할 수 있습니다.

두 뷰는 같은 프로젝트 상태와 같은 선택 상태를 사용합니다. 2D에서 선택한 배우나 소품을 3D로 이동했다고 해서 별도의 객체가 생기는 것이 아닙니다.

## 5. 배우와 소품 추가

왼쪽 패널의 `배우 +`, `소품 +`로 빠르게 추가할 수 있습니다.

추가된 대상은 오른쪽 속성 패널에서 이름, 크기, 높이, 방향 등을 조정합니다. 자주 쓰지 않는 색상·형상·세부 치수·그룹·피치 등의 값은 `세부 속성` 안에 있습니다.

배우를 선택하면 `포즈 편집` 영역을 사용할 수 있습니다.

## 6. 선택

### 일반 선택

2D와 3D 모두 작은 배우/소품도 실제 보이는 크기보다 조금 넓은 **보이지 않는 클릭 영역**을 사용합니다. 화면 모양을 키우지 않으면서 선택만 쉽게 만든 방식입니다.

큰 벽·방·세트 구조물과 작은 소품이 겹칠 때는 작은 작업 대상이 지나치게 선택을 빼앗기지 않도록 우선순위를 조정합니다.

### 겹친 대상 순환

같은 위치에 여러 대상이 겹쳐 있으면:

```text
Alt/Option + 클릭
```

을 반복해 겹친 대상을 차례로 순환 선택할 수 있습니다.

3D에서는 앞쪽 구조물 뒤에 가려진 배우/소품도 Raycaster의 전체 교차 목록을 이용해 순환 선택할 수 있습니다.

시간 입력칸을 직접 수정한 직후 Alt/Option 클릭해도 새 시간값을 먼저 playhead에 반영한 뒤 해당 프레임의 대상을 계산합니다.

## 7. 이동과 정렬

배우와 소품을 2D 또는 3D에서 직접 끌어 이동할 수 있습니다.

이동 중에는 다음 위치에 가벼운 자석식 정렬이 적용됩니다.

- 무대 중앙 X/Y
- 다른 작업 대상의 중심 X/Y

정렬이 걸리면 가이드가 표시됩니다. 강하게 격자화하지 않고 가까운 경우에만 작동하도록 범위를 작게 유지합니다.

현재 드래그에서만 정렬을 끄려면:

```text
Alt + 드래그
```

를 사용합니다.

3D의 강제 Move 핸들을 사용한 경우에도 같은 정렬 규칙이 적용됩니다.

## 8. 직접 편집 취소

대상 이동, 카메라 이동, Pose 관절 편집, 타임라인 키 이동, free-curve 핸들 편집 중 실수했다면:

```text
Esc
```

를 눌러 현재 드래그 시작 전 상태로 되돌릴 수 있습니다.

## 9. 잠금

`L`은 현재 선택 대상의 빠른 잠금 토글입니다.

- 배우/소품: 대상 편집 잠금
- 그룹 대상: 실제 transform owner 기준 잠금
- 카메라: 위치 잠금

잠금은 기존 키프레임 재생을 없애는 기능이 아니라 **편집 실수 방지** 기능입니다.

## 10. 타임라인

일상적으로 자주 쓰는 기능은 타임라인 상단에 바로 보입니다.

- 대상
- 현재 시간
- `키 +`
- 갱신
- 삭제
- 재생

보간, 경로 형태, 전체 길이 등 덜 자주 쓰는 값은 `세부 설정` 안에 있습니다.

### 시간 이동

- `Alt + ← / →` : 0.1초 이동
- `Shift + Alt + ← / →` : 1초 이동
- 시간 입력 옆 `− / +` : 0.1초
- `Shift`를 누른 채 `− / +` : 1초

### 이전/다음 키

- `[` : 현재 소스의 이전 키
- `]` : 현재 소스의 다음 키

현재 소스에 적절한 키가 없으면 통합 키 목록을 사용합니다.

## 11. Undo / Redo

기존 프로젝트 Undo/Redo 기록을 사용합니다.

- Undo: `Ctrl/Cmd + Z`
- Redo: `Ctrl/Cmd + Shift + Z`
- Windows Redo: `Ctrl + Y`

툴팁에는 현재 Undo/Redo 가능 개수가 함께 표시됩니다.

## 12. 저장과 자동 저장

관리 프로젝트를 편집하면 자동 저장 상태가 프로젝트 헤더에 표시됩니다.

예:

- 자동저장
- 서버에 기록 중
- 방금 저장
- 충돌 또는 오류 상태

데스크톱 앱이 백그라운드로 이동할 때 미저장 변경이 있으면 일반 자동저장 타이머만 기다리지 않고 즉시 비대화형 저장을 한 번 요청합니다. 기존 recovery 데이터는 추가 안전망으로 유지됩니다.

## 13. 3D 성능

대형 씬에서도 반복 편집이 무거워지지 않도록 다음 요소를 재사용합니다.

- 정적인 세트/가구 소품
- 이동하는 소품/차량 rig
- 배우 humanoid rig
- Stage Grid / Border
- 카메라 rig와 FOV geometry
- 3D motion path와 key marker
- 카메라 preview world

재생이나 단순 이동 때 구조가 변하지 않은 객체를 매 프레임 다시 만드는 대신 위치, 회전, 렌즈 등 필요한 값만 갱신합니다.

선택할 수 없는 바닥, 그리드, 경로와 장식용 helper는 불필요한 정확 Raycast 계산에서 제외합니다. 실제 배우·소품·카메라 몸체, Pose joint, gizmo와 move handle은 선택 대상으로 유지됩니다.

## 14. 내보내기

사용자에게 보이는 핵심 내보내기는 세 가지입니다.

### 기준 프레임

현재 작업 프레임을 이미지로 저장합니다. 외부 생성형 이미지 도구에서 공간과 구도의 구조 레퍼런스로 사용할 수 있습니다.

### 첫·끝 프레임

컷의 시작/끝 구조가 모두 필요한 경우 사용합니다.

### 프리비즈 MP4

Seedance Video Reference용 핵심 출력입니다.

MP4 구간 시작/끝은 일반 작업에서 계속 보이지 않도록 `MP4 구간 설정` 안에 있으며 필요한 경우만 펼칩니다.

FrisFrame 안에서 최종 Seedance 프롬프트를 작성하거나 배경 이미지를 생성하지 않습니다.

## 15. MCP 보조 작업

MCP를 사용하면 자연어와 이미지 해석은 **외부 vision-capable MCP 클라이언트**가 담당합니다.

```text
레퍼런스 이미지 + 사용자 지시
        ↓
외부 MCP 클라이언트가 이미지/의도를 해석
        ↓
구조화된 FrisFrame 명령
        ↓
무대 · 카메라 · 배우 · 소품 · 키프레임 생성
        ↓
FrisFrame에서 수동 수정 가능
```

FrisFrame MCP는 AI API를 호출하지 않습니다. 전달받은 결정된 값만 프로젝트에 기록합니다.

주요 MCP 동작은 다음과 같습니다.

- `list_projects`
- `get_project`
- `apply_stage_layout`
- `apply_motion_timeline`
- `apply_motion_macros`
- `apply_previs_plan`

지원 모션 매크로에는 camera orbit, dolly+zoom, actor follow, pair approach, generic subject movement 등이 있습니다. 매크로 결과도 일반 FrisFrame 키프레임으로 저장되므로 이후 UI에서 직접 수정할 수 있습니다.

수동 편집과 MCP 편집을 섞을 때는 최신 `revision`을 기준으로 작업합니다. 오래된 revision을 가진 MCP 요청이 더 최신 수동 편집을 조용히 덮어쓰지 않도록 충돌 검사가 적용됩니다.

## 16. 데스크톱 MCP 실행파일

설치본에는 별도의 stdio MCP 실행파일이 포함됩니다.

macOS:

```text
FrisFrame.app/Contents/Resources/runtime/mcp/frisframe-mcp
```

Windows:

```text
FrisFrame 설치폴더/resources/runtime/mcp/frisframe-mcp.exe
```

이 실행파일은 데스크톱 FrisFrame이 사용하는 플랫폼별 managed-project DB 위치를 자동으로 찾아 같은 프로젝트를 사용합니다.

`PREVIS_DB_PATH` 환경변수를 지정하면 별도의 DB 경로를 명시적으로 사용할 수도 있습니다.

## 17. 프리비즈 이후

프리비즈가 확정되면 기준 프레임 또는 첫·끝 프레임을 외부 생성형 이미지 도구의 구조 레퍼런스로 사용할 수 있습니다.

필요한 이미지 에셋 예:

- 배경
- 인물
- 소품
- 복잡한 상호작용 구조 이미지

이 작업은 FrisFrame 밖에서 진행합니다.

최종 단계에서는 외부 MCP 대화에 필요에 따라 다음을 함께 전달합니다.

- FrisFrame 프리비즈 MP4
- 생성한 이미지 에셋
- 컷 설명

그 외부 대화가 최종 Seedance 프롬프트와 레퍼런스 배치를 구성합니다.

## 18. 제품 경계

FrisFrame이 책임지는 것:

- deterministic 2D/3D blocking
- 카메라/배우/소품 키프레임
- 타이밍과 공간 관계
- 프리비즈 재생
- 기준 프레임
- 첫·끝 프레임
- Seedance Video Reference용 MP4
- 외부 MCP 클라이언트가 사용할 deterministic 명령 표면

FrisFrame 밖에서 처리하는 것:

- 레퍼런스 이미지 의미 해석
- 생성형 배경/인물/소품 이미지 제작
- 최종 AI 영상 생성
- 최종 Seedance 프롬프트 작성

이 경계를 유지하는 것이 FrisFrame의 결과를 예측 가능하고 수동으로 수정 가능하게 만드는 핵심 원칙입니다.
